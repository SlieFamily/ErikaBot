**美图发送** 命令：`setu|涩图|色图|来点涩图`（图发完之后**再**接一句`不够色` ~~或者`加大剂量`~~ 试试）

**语录清单** `侦探的棋子名单` 对应 *普通语录清单*
				`侦探的魔女名单` 对应 *高级语录清单*
				`[语录名称]语录(-n)` 则回复随机/第 $n$ 条该语录的记录

**添加语录** `QQ回复[需要加入语录的内容，图片/表情等]：add[语录名称]语录`

**删除语录** `del [语录名称]语录-n` 删除第 $n$ 条语录

**查找语录** `find：[需要查找的语录内容]`

**高级语录** 若`[语录名称]`中带`<高级>`的后缀，则触发关键词即可回复随机语录

​                如：`发送：今天吃什么` 则`回复：紫菜蛋花汤`

**RSS订阅** `关注列表`查看本群关注清单，`关注[app名称]：[用户ID]`进行关注（当前支持 微博、B站、bili直播）

**倒计时** 每天8点**自动提醒**相关考试或日程的剩余天数

​             也可以通过`倒计时`、`考试`等命令触发

## DSH 角色聊天桥接

`agent_chat` 插件由 NoneBot 管理 QQ 收发，DSH 管理模型、API Key、持久会话和历史压缩。插件默认关闭，启用后只处理管理员配置的群和私聊。

| 已实现能力 | 行为与边界 |
| --- | --- |
| 人设聊天 | 独立 Markdown 角色卡；各群共用已安装的人设，历史按机器人账号和对话隔离 |
| @、引用与随机接话 | @ 或引用机器人无需概率抽签；普通消息可按概率接话，模型仍可选择沉默；原有命令和实际语录回复优先 |
| 主动发言 | 按群闲置时间调度、夜间静默、每日尝试额度；无人回应就不继续，重启保留额度 |
| 读图 | 当前消息、引用与近期上下文图片可作为原生图片送入视觉模型；无 @ 时也可由随机接话触发 |
| 联网搜索 | AI 自主调用 DSH 原生 AnySearch web_search，同回合消化；保留来源、额度和超时限制 |
| 提示词优化 | 首次载入完整人设，后续只带短提醒和新增聊天；重启续用进度，历史压缩后补充人设 |
| 输出与执行限制 | 过滤已识别的思考标签；只发送普通文本；DSH 执行端仅允许经过本轮授权的原生搜索，聊天不能授予命令、文件或管理权限 |
| 运维 | `ai 状态` / `ai 重置`；断线、超时和结果不确定时暂停，避免盲目重复发送 |

角色卡未被缩减。增量提示减少历史中的重复内容；API 仍可能对系统提示和已有上下文计费，不能把新增字符的降幅当成账单降幅。AnySearch 原生联网搜索已实现，语音识别按计划延期，完整等待/自主唤醒机制仍待实现。

配置、消息触发规则、安全边界和保持 QQ 在线的测试/部署步骤见 [agent_chat 文档](docs/agent_chat.md)。

默认人设为 [古户绘梨花](roles/古户绘梨花.md)，使用独立 Markdown 文件保存；修改或替换方法见 [角色设置说明](roles/README.md)。联网搜索边界及与 qq-bridge 的功能对照见 [agent_chat 后续计划](docs/agent_chat_roadmap.md)。
