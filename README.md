## DSH 角色聊天桥接

`agent_chat` 插件由 NoneBot 管理 QQ 收发，DSH 管理模型、API Key、持久会话和历史压缩。插件默认关闭，启用后只处理管理员配置的群和私聊。

| 已实现能力 | 行为与边界 |
| --- | --- |
| 人设与主人识别 | 独立 Markdown 角色卡；各群共用已安装的人设，历史分群隔离；按真实 QQ 号认主人，与管理权限分开 |
| @、引用与随机接话 | @ 或引用机器人无需概率抽签；普通消息可按概率接话，模型仍可选择沉默；原有命令和实际语录回复优先 |
| 主动发言与观察 | 闲置主动发言有每日额度、夜间限制；成功发言后可观察相关新消息，无新消息不调用模型，续聊有时间和次数上限 |
| 读图优化 | 当前附图、引用和明确看图追问；跨轮去重、内存缓存及 DSH 原生历史图片省略，普通文字聊天不重复带旧图 |
| 联网搜索 | AI 自主调用 DSH 原生 AnySearch web_search，同回合消化；保留来源、额度和超时限制 |
| 提示词优化 | 首次载入完整人设，后续只带短提醒和新增聊天；重启续用进度，历史压缩后补充人设 |
| 记忆与黑话 | 即时记忆 + 后台增量整理；黑话自主理解、按需搜索、自动修订；管理员可修改、锁定、批量确认和回退，后台工作会话跨重启复用 |
| 合并转发报告 | `ai 记忆` 易读分类展示；`ai 黑话` 在 AI 群只列本群来源，在非 AI 审核群集中展示；小页翻阅、失败不展开刷屏 |
| QQ 互动 | 读取最多两层合并转发；自主引用、@群友、emoji、QQ 自带表情、消息贴表情及戳一戳；被戳可按独立概率回应 |
| 输出与执行限制 | 过滤已识别的思考标签；校验引用和互动目标；只开放本轮授权的搜索及有界记忆/词库工具，聊天不能授予主机或管理权限 |
| 运维与恢复 | 连续提问后台合并；`ai 恢复` 可接管手动输入、跳过不确定旧回复并保留历史；批量更换模型、日志定位、内容拦截诊断；恢复不代替 API 修复 |

本机配置快照（2026-10-28）：每群90轮/小时、随机接话2%、发送后观察60秒且最多3次判断、闲置15分钟后每日最多6次主动尝试；23:00–09:00只停止闲置主动发言。仓库默认关闭 AI、随机接话、观察和自主发言；这些值可在私有配置调整，详见[配置对照](docs/agent_chat.md#当前部署节奏与仓库默认值)。

增量提示减少历史中的重复内容；API 仍可能对系统提示和已有上下文计费，不能把新增字符的降幅当成账单降幅。语音识别按计划延期，“等用户说完”、网页全文读取和角色热切换尚未实现；按需求不安排表情图片发送与每群独立环境。

配置、消息触发规则、安全边界和保持 QQ 在线的测试/部署步骤见 [agent_chat 文档](docs/agent_chat.md)。
