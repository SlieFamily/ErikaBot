# 魔导书|详细功能介绍

## DSH 角色群聊（agent_chat）

配置后，可 @ 绘梨花、引用她的消息与她聊天或问图；也可开启随机接话和安静时的主动发言。默认插件关闭、随机概率为 0、自主发言与读图关闭，需在 `.env.agent_chat` 中逐项开启。模型必须支持视觉输入才能读图。

当前具备独立角色卡、跨重启的分群会话、完整人设首次载入与后续短提醒、增量聊天、思考标签过滤、调用限流和执行端工具白名单。普通消息命中随机概率只表示安排一次模型调用，模型可以顺着群友互聊接梗，也可在不适合插话时选择 `[SILENT]`；@ 和引用机器人也受调用额度、会话状态、消息仲裁及合并处理约束；直接提问若明确返回 `[SILENT]` 会转成澄清提示，不能保证每条原消息各发一条答案。

`ai 状态` 查看当前对话和功能开关，`ai 恢复` 核验后恢复暂停会话并保留记忆，`ai 重置` 清理当前映射后重新建立会话，均仅限 NoneBot 超级用户。默认 AI 接管指向机器人的消息；既有显式命令优先，`their_ana` 实际发出语录时 AI 不重复回复。关闭 AI 或关闭接管后保留原有语录路径。

联网搜索已支持：开启 `AGENT_CHAT_SEARCH_ENABLED` 后，AI 自主调用 DSH 已安装的 AnySearch web_search，再消化资料回复并按需附来源；凭据与用量由 DSH/AnySearch 管理。随机/主动发言的搜索默认关闭；完整等待机制和语音识别尚未实装。配置与全部边界见 [agent_chat 使用说明](agent_chat.md)，角色与群配置见 [角色设置](../roles/README.md)，与参考项目的差异见 [后续计划](agent_chat_roadmap.md)。

轻量长期记忆与黑话学习已实现：自动维护当前群的话题、短期念头和具体群友印象；从群聊自主归纳黑话，必要时自行调用 AnySearch，解释自动生效并迭代；超级用户可纠正、锁定、解锁或回退。`ai 学习帮助` 查看记忆清理、词条审核和手工添加命令；`ai 重置` 保留这些独立记录。开启方法、费用和共享范围见 [记忆与黑话说明](agent_chat.md#轻量长期记忆与黑话学习)。

### 日常互动与管理

超级用户可用 `ai 状态`、`ai 恢复`（保留原会话记忆、不重发旧消息）、`ai 重置`（下次建立新会话）。恢复可停止本群旧任务、接管已结束的 DSH 手动输入、跳过送达不确定的旧回复；保留原历史，未答的问题需要重新提问。仍须核对预设、结束回合和空队列，不能修复聊天 API 故障，也不能清除被服务商拦截的旧上下文。模型可自主引用当前聊天近期消息，使用 emoji／QQ 自带表情；收到的合并转发可受限展开文字和图片。不会发送表情图片。详见 [agent_chat 使用说明](agent_chat.md)。

发送后观察：成功发言后开启观察，代码默认120秒，本机配置60秒（均可调节），相关新消息最多触发3次无@续聊判断；AI可沉默结束，不增加首条回复前的等待。配置见 agent_chat 文档。

被戳回应：白名单群有人戳机器人时，默认70%不调用模型，30%由AI自主决定回应或沉默；独立概率和30秒冷却可在 `.env.agent_chat` 调整。

`ai 记忆`：以合并转发展示本群有效记忆，隐藏编号/英文标签，每条空行分隔。支持 `话题`、`想法`、`群友` 分类与页码；需要删除编号时用 `ai 记忆 管理`。只改展示，不调用模型或改写存储内容。

主动互动：模型可自主引用近期消息、@最多两位同群参与者、在正文使用 emoji/QQ 自带表情、给一条消息贴表情或戳一人；不强制每次使用。仅允许本轮观察到的真实同群目标，贴表情和戳人有独立冷却，附加动作失败不重发正文。

`ai 黑话`：AI 开启群只看本群有来源的词，在非 AI 审核群按来源群集中展示。每页最多12次词条展示、2200正文字符、3个来源段加1个说明节点；`ai 黑话 2` 翻页，不会自动连发所有页。可用 `候选`、`自动`、`已锁定`、`已拒绝` 筛选，`全部` 只放宽词频，不改变群范围。没有 QQ 送达回执时先核对卡片是否已出现，避免重复发送；报告失败不代表 DSH 聊天暂停。

| 常用命令（仅 SUPERUSER） | 用途 |
| --- | --- |
| `ai 即时记忆 开/关`、`ai 后台记忆 开/关` | 控制当前群的记忆写入路径，立即生效；加 `全群` 可统一设置 |
| `ai 记忆状态`、`ai 记忆开关 开/关` | 查看整理队列/预算或控制记忆总开关，关闭不删已有记录 |
| `ai 忘记 编号`、`ai 清空记忆 [类别]` | 清理当前群独立记忆；编号从 `ai 记忆 管理` 查看 |
| `ai 黑话确认 12 15 18` | 用空格分隔，批量锁定各自已有解释，最多30条 |
| `ai 黑话确认` 后换行，每行 `编号 \| 解释` | 一次人工填写多个不同解释并锁定；单条 `ai 黑话确认 12 解释` 仍可用 |
| `ai 黑话添加 词语 \| 解释` | 手动添加/修改共享词条并锁定 |
| `ai 黑话解锁 12 15` | 允许 AI 再按新语境自动修订 |
| `ai 黑话历史 12`、`ai 黑话回退 12 3` | 查看旧版本或回退到指定版本并锁定 |
| `ai 黑话拒绝 编号`、`ai 黑话删除 编号` | 停用或删除词条 |
| `ai 学习帮助`、`ai 黑话帮助` | 查看完整命令、参数与共享范围 |

黑话的查看与审核可在机器人所在的非 AI 群操作，不会为该群开启聊天或收集群消息。记忆查看、开关和会话管理只用于已开放的当前对话。管理命令不会调用模型，人工开关可能影响后续后台用量；“人设主人”由 `AGENT_CHAT_OWNER_IDS` 按 QQ 号识别，不会因此自动获得 `SUPERUSERS` 权限。

本机配置（2026-10-28）为每群90轮/小时、随机2%、排队上限600秒、单轮执行上限300秒、观察60秒；闲置15分钟后每日最多6次主动尝试，23:00–09:00只停止这类闲时发言。合并一批提问算一轮，沉默/失败尝试也占额度；后台记忆与黑话另用全局12轮/小时预算。修改入口及仓库默认值见[配置说明](agent_chat.md#当前部署节奏与仓库默认值)。

## 语录放送

> 基于`sqlite3`**轻量数据库**的自定义语录放送功能

### 语录清单

命令：

```bash
侦探的棋子名单 #普通语录清单
侦探的魔女名单 #高级语录清单
```

* 注：采用**合并转发**的方式给出

### 发送语录

```bash
[语录名称]语录(-n)
```

通过上述命令直接触发语录。其中，`[语录名称]`是用于检索的关键词，如：

发送命令：`战人语录`，如果数据库中已有该语录，则可以在存入数据库的语录中**随机**发送一条

发送命令：`战人语录-100`，则返回数据库的语录中发送第 `100` 条记录（如果有100条以上的话）

发送命令：`战人语录-max`，则返回数据库中最后添加的记录

### 添加语录

```shell
add [语录名称]语录：[需要加入语录的内容，图片/表情等]
# 或者
QQ回复[需要加入语录的内容，图片/表情等]：add[语录名称]语录
```

### 删除语录

```bash
del [语录名称]语录-n #删除第 n 条记录
# 或者
QQ回复[需要删除语录的内容，图片/表情等]：del[语录名称]语录
```

### 合并语录

```bash
merge [语录名称1]语录，[语录名称2]语录
```

* 将 *语录2* 与 *语录1* 合并为 *语录1*，并将 *语录2* 删除

### 销毁语录

> 只对`SUPERUSERS`的命令进行响应

```bash
drop [语录名称]语录
```

* **将整个语录全部删除**

### 查找语录添加信息

> 支持**模糊匹配**

```bash
find：[需要查找的语录内容，可以是图片/表情等]
```

### 设置不可见

> 只对`SUPERUSERS`的命令进行响应

```shell
lock [语录名称]语录
unlock [语录名称]语录
```

### 设置 *高级语录触发*

开启该功能后可以不用加上**后缀** `语录`，并且只要一句话中**含有**`[语录名称]`即可触发，如：

发送：`我真的好喜欢战人呀~`；机器人检索到`战人`二字后，会随机发送一句隶属于`战人<高级>语录`中的语句。

**对于高级语录，只需要在创建时使用`[语录名称]<高级>语录`进行追加**

## RSS更新推送

> **【已废弃原方案】**基于`Selenium`自动化爬虫实现，**参考**项目地址：[nonebot-twitter](https://github.com/kanomahoro/nonebot-twitter)

> 只对`SUPERUSERS`和`ADMIN`的命令进行响应

```bash
关注列表 #查询当前群聊所关注的用户
关注[app名称，目前可选 -bili直播, -微博, -B站]：[用户ID] #关注指定平台的用户
取关 [用户ID]
```
