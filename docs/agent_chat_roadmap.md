# agent_chat 后续计划

更新日期：2026-10-25。保留用户提出的五个方向；读图和自主发言已实现，语音识别按用户最新决定延期。

| 功能 | 预期体验 | 实施时要解决的边界 |
| --- | --- | --- |
| 联网搜索 | 查作品、国 V 公开资料和近期消息，能依据来源接话 | 专用受限搜索入口；网页是外部资料，不能覆盖角色或执行规则；不直接恢复通用 shell、文件、MCP 工具权限 |
| 等待新消息 | 群友话没说完时等待，收到后续再接，不抢答 | 等待、超时、取消和重启恢复；同群消息去重、合并；不要长期占用模型调用或并发槽 |
| 自主发言（已实现） | 安静时有分寸地开口；随机接话也已完善 | 每群安静时间、夜间静默、每日预算和无人回应后停止，持久化状态；沿用白名单和 their_ana 仲裁 |
| 识别图像（已实现） | 理解图片、截图和表情包，结合群聊回应 | 受限 CDN 下载、DNS 固定连接、格式和像素校验、原生 DSH 图片输入；动态图首帧，失败诚实说明 |
| 识别音频（用户决定延期） | 后续再接入语音识别 | 当前 NapCat 能获取语音但无转写动作；以后选择离线识别或 API，并设置时长、格式、隐私和失败回退规则 |

联网搜索和完整“等待后续消息”机制仍未实现。现有 2 秒消息合并不等于完整等待机制。语音、视频目前仍只有占位符；读图、随机接话与自主发言的实际配置见 [功能说明](agent_chat.md)。

已完成独立 Markdown 人设、古户绘梨花角色卡、安装器选卡与完整人设模式、[角色设置说明](../roles/README.md)，并修复正文思考标签泄露。安全守卫继续默认拒绝全部 DSH 工具；图片获取和发言调度由受限的 NoneBot 代码完成，未开放 shell、文件工具、MCP 或子代理。
