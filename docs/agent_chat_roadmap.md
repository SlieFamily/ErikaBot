## 已实装的联网搜索

采用模型自主决策 → DSH 原生 `web_search` → AnySearch 返回结果 → 模型在同一回合消化 → QQ 最终文本。Python 不再执行网络搜索。每轮最多两次搜索，每次一个公开主题、三个来源；不开 `web_fetch` 或高级批量工具。与原 qq-bridge 相比，已有受限的原生多步搜索，已有黑话专项研究草稿，但尚缺网页正文读取、更长的工具循环及通用研究工作流。配置、费用与边界见 [搜索说明](agent_chat.md#ai-自主联网搜索anysearch)。

上游参考：[搜索实现](https://github.com/Derpyu520/qq-bridge/blob/main/src/web-search.js)、[MCP 包装](https://github.com/Derpyu520/qq-bridge/blob/main/src/mcp-web-search-safe.js)。

## 稳定性后续增强（尚未实现）

当前会捕获 DSH 故障并隔离到 AI 请求，部分阶段会暂停群会话以避免重复发送；完整现状见 [断线与恢复](agent_chat.md#dsh-关闭断线与恢复)。已增加经过队列、回合、输入来源和发送状态核查的 `ai 恢复`，保留原会话记忆、不重发旧消息。可继续增加：只暂停 AI 的运行时维护开关、全局故障熔断与限频健康探测、明确区分实时健康与本地状态、日志轮转与脱敏导出。

自动恢复必须能证明旧请求已结束且没有待发送结果；不应仅因端口恢复就自动重放失败消息、解除所有暂停或切换到普通智能体。此处是计划，本轮没有为验证健壮性停止生产机器人或关闭真实 DSH。

## 与原 qq-bridge 相比还差什么

核对日期：2026-10-26；参考上游公开 `main`、README 标注的 `v0.2.1-r1` 及当前源码。下面区分实际功能差距与本项目主动保留的权限边界；原项目不同运行模式行为并不完全相同。

| 能力 | 原 qq-bridge | 当前 agent_chat | 后续判断 |
| --- | --- | --- | --- |
| 角色聊天与持久会话 | 多运行模式、角色注入/读取、分会话持久化 | 已有角色卡、分群会话、自动压缩适配、增量投递 | 核心体验已有；不是所有上游路径都逐轮附完整卡 |
| 联网搜索与正文获取 | `web_search` / `web_fetch`，工具循环可多次查询 | 已有 DSH AnySearch 原生搜索、最多两次查询、同回合消化和来源链接 | 尚缺网页全文、更长检索与研究流程 |
| 等待与自主唤醒 | v2 可取未读消息、长轮询等待、设置潜水和唤醒条件 | 1 秒批量合并、可配置概率抽签（当前 5%）、按闲置时间主动开口 | 尚缺模型选择等待对象、条件和时间，以及更完整的参与状态机 |
| 独立长期记忆 | v2 有话题、待表达想法、成员印象的持久化工具 | 已实现相同三类记录、六个记忆/词库工具中的四个记忆工具及管理命令 | SQLite 持久化、群友 ID 校验、快照增量；有限容量与过期，非无限记忆 |
| 黑话/梗学习 | 查询、提交候选词条、检索研究与人工确认 | 已实现提取、计数、AnySearch 研究草稿、人工确认和共享词库 | 不抓网页全文；后台有预算和超时，未知梗可手动补解释 |
| 图片与更多消息类型 | 图片/表情兜底、按消息取图、合并转发读取等 | 当前/引用/近期图片及受限两层合并转发；动态图首帧 | 仍缺更深转发、更多表情兜底和按需精细取图 |
| QQ 表达动作 | 模型可分多条发送、主动选择引用、戳一戳、发送/收藏表情 | 已有主动引用、emoji 和有限 QQ 自带表情，每次一条 | 分条与拍一拍未实现；按用户选择不做表情图片发送/收藏 |
| 语音 | 有受限语音库发送；转写相关能力依赖网关，部分语音工具已独立拆出 | 听语音延期，AI 发语音未接入 | 不能把上游“发语音”当成已具备通用语音识别或音色理解 |
| 设置与角色管理 | 本地 Web 控制台、角色编辑/切换、模式切换、分会话初始说明 | 私有 env + Markdown + 安装器；`ai 状态/恢复/重置` | 缺网页控制台和角色热切换；每群独立环境说明按用户选择不安排 |
| 用量与费用 | 有 token、缓存与费用看板 | 只有请求额度、状态和日志；暂无用量报表 | 可后续读取 DSH 用量投影；应区分字符、token、缓存和实际账单 |
| QQ 控制宿主 | `closed-agent` 等路径可面向 owner 开放完整工具、审批与控制命令 | 聊天仅允许经授权的搜索及有界记忆/词库工具，拒绝主机操作和控制命令透传 | 有意不移植到群聊桥接，不以功能追平为由放开主机权限 |

2026-10-26 已优先实现保留记忆的恢复、主动引用、合并转发阅读、emoji 与 QQ 自带表情。轻量长期记忆与黑话学习也已实装；后续可考虑等待/自主唤醒和用量看板；每群独立环境和表情图片发送不安排，语音识别继续延期。
