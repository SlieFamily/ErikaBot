| 功能 | 预期体验 | 实施时要解决的边界 |
| --- | --- | --- |
| 联网搜索 | 查作品、国 V 公开资料和近期消息，能依据来源接话 | 专用受限搜索入口；网页是外部资料，不能覆盖角色或执行规则；不直接恢复通用 shell、文件、MCP 工具权限 |
| 等待新消息 | 群友话没说完时等待，收到后续再接，不抢答 | 等待、超时、取消和重启恢复；同群消息去重、合并；不要长期占用模型调用或并发槽 |
| 自主发言 | 根据话题、群活跃度或安静时长，有分寸地开口 | 每群独立开关、安静时段、每日预算、连续无人回应时停止；沿用白名单和与 their_ana 的仲裁 |

| 识别音频 | 理解语音消息，结合说话内容回应 | 音频获取、格式/时长限制、转写或音频模型、失败回退与临时文件清理；不把转写内容视为控制命令 |
